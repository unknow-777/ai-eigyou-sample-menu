# MELA! 街中QR体験 — Experiment #001

既存のMELA!営業サイト・店舗向けデモ・管理画面とは**完全に独立**した試作品です。
「ブランドコンセプトだけ共有する別実験」として、このフォルダ以外の既存ファイルには一切変更を加えていません。

## 実験目的

MELA!のコンセプト「外国人への説明を、QRひとつに。」を、店舗への営業なしで、街中で数秒だけ疑似体験してもらう。

体験の流れ：

1. 外国人観光客が携帯するカード/タグに日本語の一文だけが書かれている（例:「この意味が分かりますか？」）
2. 気になってQRを読み込む
3. 営業説明を挟まず、まず「さっきの日本語の意味」がそのまま表示される
4. 直後に「今のその感覚こそがMELA!の価値」という一文が続く
5. 最後に小さくMELA!ロゴ

成功基準は「サイトの完成度」ではなく、**気になる→QRを読む→意味が分かる→MELA!を直感的に理解する**が3〜5秒で成立するかどうか。

## ファイル構成

```
experiment/001/
├── index.html   … QRを読み込んだ後に表示されるスマホ用体験ページ（本体）
├── card.html    … 街中で携帯するA4印刷用カード（日本語見出し＋QR）
└── README.md    … このファイル
```

## QRリンク

`card.html` のQRコードは以下のURLを指しています（GitHub Pages公開後に有効）:

```
https://unknow-777.github.io/ai-eigyou-sample-menu/experiment/001/index.html
```

QR画像は `api.qrserver.com` の無料API（外部サービス、アカウント不要）でその場生成しています。埋め込みQRライブラリを持たないため、`card.html` を開く/印刷する端末はインターネット接続が必要です。

## カードの使い方

1. ブラウザで `card.html` を開く
2. 右上「印刷 / PDF保存」ボタンでA4サイズのPDFとして保存、または直接印刷
3. リュック・トートバッグ・首掛けカードなど、身につけられるものに貼る/挟む

## 多言語

- 初期表示言語は `navigator.language` から自動判定（`zh*`→中文、`ko*`→한국어、`ja*`→日本語、それ以外→English）
- 常に手動切替（English / 中文 / 한국어 / 日本語）を画面上部に表示
- 翻訳文は `index.html` 内 `EXPERIMENT.copy` オブジェクトにすべてまとめてあります

## 計測（最小構成）

現時点ではバックエンドを持ちません。`index.html` 内の `track(eventName, data)` 関数が、

- `console.log` への出力
- `localStorage`（キー: `mela_experiment_events_v1`、最大200件）への蓄積

のみを行い、以下のイベントを記録します。

| イベント | タイミング |
|---|---|
| `page_view` | ページ読み込み時（`experimentId`・初期言語・UAを記録） |
| `lang_view` | 言語が表示/切替された時 |
| `reached_final_message` | 最後の一文（MELA!の価値説明）まで到達した時（読み込み後0.9秒で発火） |
| `leave` | タブが非表示になった時 |

将来、実際のアクセス数・言語比率・到達率を集計したくなった場合は、`track()` の中身だけを、任意の記録先（例: 営業管理台帳とは別系統の、独立したGoogle Apps Script Web App／Google Sheets）へ送信するように差し替えてください。**既存の営業管理台帳・Gmail営業機能とは統合しないこと。**

## Experiment #002以降の追加方法

1. `experiment/001/` フォルダを丸ごと `experiment/002/` などにコピー
2. `index.html` 内の `EXPERIMENT` オブジェクト（`id` / `streetMessageJa` / `copy.*`）だけを書き換える
3. `card.html` 内の `EXPERIMENT_ID` / `HEADLINE_JA` / `PAGE_URL` を書き換える
4. ページ構造・CSS・計測ロジックは変更不要（コピー元と共通のまま使えます）

これにより「日本語メッセージだけを差し替えたA/Bバリエーション」を、既存ページを大改造せずに増やせます。
